# frontiergifts
To unveil the beauty of Jesus and reveal your giftings

## Find Your Place at Frontier
A short, story-driven serving-discovery experience for Frontier Church. It is a guided conversation that helps people feel known, understand Frontier's heart for serving, and discover a few meaningful places to begin across six teams: Tech and AV, Welcome, Setup and Breakdown, Worship, Kids Ministry, and Prayer Ministry. It also offers gentle reflections on the gifts named in Romans 12.

**Prototype status:** a static web app. Answers stay in the browser. Nothing is sent anywhere, and there are no accounts, analytics, or external AI.

```bash
npm install
npm run dev     # http://localhost:5173
npm test
```
